Сведения о реализуемых требованиях к защите персональных данных

Timchenko.pro · редакция 11.08.2026

Оператор — Индивидуальный предприниматель Тимченко Виталий Вадимович. Здесь приведено общедоступное описание мер без раскрытия сведений, способных снизить безопасность систем.

Организационные меры

  • определение целей, состава и сроков обработки;
  • разграничение доступа по принципу необходимости;
  • учёт обращений субъектов, отзывов согласий, блокирования и уничтожения данных;
  • регламент реагирования на инциденты;
  • периодический пересмотр прав доступа и состава данных.

Технические меры

  • HTTPS для сайта и клиентского интерфейса;
  • первичная российская база данных для заявок;
  • пароли, BOT_TOKEN и другие секреты хранятся вне публичного web-каталога;
  • отдельный пользователь MySQL с минимальными правами;
  • обновление программного обеспечения и резервное копирование;
  • ограничение частоты обращений к публичным API и журналирование событий;
  • клиентский доступ только к данным привязанного объекта.

Минимизация

Формы запрашивают только данные, необходимые для обработки заявки. Аналитические и рекламные трекеры в базовой конфигурации сайта не используются.
